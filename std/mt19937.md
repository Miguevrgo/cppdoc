Mersenne Twister pseudo-random number generator producing 32-bit integers with a state size of 19937 bits.

## Definition

```cpp
template<
    class UIntType, std::size_t w, std::size_t n, std::size_t m, std::size_t r,
    UIntType a, std::size_t u, UIntType d, std::size_t s,
    UIntType b, std::size_t t, UIntType c, std::size_t l, UIntType f
> class mersenne_twister_engine;
```

Standard fast pseudo-random number generator with an extremely long period ($2^{19937} - 1$). For 64-bit platforms, `std::mt19937_64` is also available.

## Examples

```cpp
#include <cassert>
#include <random>

std::random_device rd;
std::mt19937 gen(rd());

unsigned int n = gen();
assert(n >= gen.min() && n <= gen.max());
```
